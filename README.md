### Le Chatelier's Principles Quiz

This is a chemistry quiz game based on Le Chatelier's Principle.

Le Chatelier's Principle states that if an equilibrium is disturbed by changing the conditions, the position of equilibrium shifts to counteract the change and re-establish equilibrium.

In simple terms, if pressure is exerted on the system, it will try its best to maintain its state. For example, if you add more reactants, more products will be made.

This quiz explores changes in:

- Temperature
- Volume
- Concentration
- Qc vs. Kc

There are 20 questions in total, and you'll need to get about half right to pass.... and beware of Louis Le Chatelier.

I hope this helps future Chem students who are struggling in their class!! 

### Why I Made This Game

I made this game because Le Chatelier's Principle absolutely destroyed me in AP Chemistry. I understood the idea eventually after way too many study sessions and watching my YouTube chemistry gurus, but I kept thinking, "This would've been so much easier if I could just spam practice questions."

The problem was I couldn't find one that covered temperature, volume, concentration, and Qc vs. Kc all in one place.

So... I made one.

### What I Struggled With
I severely underestimated how hard it would be to turn chemistry into code.
- The concentration questions gave me the most trouble because my original dictionary system wouldn't regenerate random values. I eventually rebuilt that part inside the game manager instead.
- I forgot to make a question filtering system until halfway through development, so I had to go back and restructure a bunch of code.
- Uploading to itch.io completely broke my UI. Learning about anchors saved me cause they would "anchor" the UI to a specific spot and it would resize perfectly without any problems !!.

This project taught me a lot about Godot, UI design, and debugging. I'm honestly just proud I managed to get both the chemistry and the code working without losing my mind.

### Built With
Godot and GDScript

### Clone/ download game 
1. Download the **Source code (zip)** file automatically generated under the Assets list (or clone this repository).
2. Extract the folder completely.
3. Open the **Godot** on your computer.
4. Click the **Import** button.
5. Browse to the extracted source folder, select the `project.godot` file, and click opem.
6. Enjoy the game!
